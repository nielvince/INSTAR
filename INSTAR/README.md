# Hunnypie - Facebook theme

Homepage only: same masonry feed, infinite scroll and pull-to-refresh as Hunnypie, styled like Facebook.

## Setup

1. Copy your photos into `assets/images/` (same file names as in `src/data/pins.ts`).
2. Run:

       npm install
       npm start

Scan the QR code with Expo Go (SDK 58). If your phone can't reach your PC, use `npm run tunnel`.
